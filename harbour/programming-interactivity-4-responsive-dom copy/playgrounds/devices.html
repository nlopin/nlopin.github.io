Your screen, right now

A CSS pixel is not a screen pixel. A phone that is 390 CSS pixels wide may have 1170 physical pixels across: a device pixel ratio of 3. Media queries, vw and every px in your CSS use CSS pixels. Zoom your browser (⌘ +) and watch the numbers above: the CSS width shrinks, the ratio grows.
