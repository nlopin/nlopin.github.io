Scrollburglars

A scrollburglar is anything that makes a page wider than the phone, so the whole page slides sideways under your thumb. The preview is a 360px phone. The detector outlines each burglar in red: the outermost box that sticks out.

On your own pages (a line of JavaScript: after the break you'll read it easily): DevTools console, paste [...document.querySelectorAll("*")].filter(e => e.getBoundingClientRect().right > innerWidth). It lists every element that ends past the right edge. The first one in the list that isn't a parent of the others is usually your burglar.

🦝

Six burglars, one phone

On my phone the whole page slides left and right. I keep thumbing it back.

Each burglar is a different classic. Catch them in any order: the 🦝 badges tell you who's still loose, and the checks tick off each one. Some hints, if you want them:

  • .banner — 100vw is the width of the whole window, but the banner starts 16px in.
  • .poster — an image with a fixed width. One declaration makes every image in the world behave.
  • .link — a word can't wrap if it has no spaces… unless you let it (overflow-wrap).
  • .stalls — the magic line with a 22rem minimum: wider than the phone. min() knows two sizes.
  • .ticker — nowrap on purpose. Let it scroll inside its own box instead of moving the page.
  • .stamp — hangs off the promo's edge. The promo can cut it off: overflow: clip.
Solution

Six fixes, six patterns worth remembering:

.banner { width: auto; }        /* a block fills its parent anyway */
.poster { max-width: 100%; height: auto; }
.link   { overflow-wrap: anywhere; }
.stalls { grid-template-columns: repeat(auto-fill, minmax(min(22rem, 100%), 1fr)); }
.ticker { overflow-x: auto; }   /* scrolls inside its own box */
.promo  { overflow: clip; }     /* like hidden, but not a scroll box:
                                   sticky children still work */
Why not body { overflow-x: hidden }?

It hides the symptom and keeps the bug: the content is still cut off, you just can't scroll to it any more. It also breaks position: sticky for everything inside (the body becomes the scroll container). Find the burglar; don't lock the door with it inside.
