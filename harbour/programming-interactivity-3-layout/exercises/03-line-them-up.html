Act 3 · Flexbox

Line them up

The flex problems of the market page, one per case. The red arrow on each flex container is its main axis (justify-content), the blue one the cross axis (align-items). Cases 1–3 and 6 in class; 4 and 5 if you finish early.

Before you type, ask two questions. ① Which element is the parent of the things I want to line up? display: flex goes there. ② Which way do I want to move them: along the main axis or across it?

1

Logo left, menu right

The menu is a list going down. It should be logo on the left, menu on the right, all on one line.

Two flex containers: the header .site-header (its children: logo + nav) and the list .main-nav ul (its children: the links). Links 1.5rem apart, the logo and the menu vertically centred on each other.

Why it works

display: flex only lines up direct children. The header's children are the logo and the nav, so the header gets justify-content: space-between. The links are children of the ul, so the ul is the second flex container. align-items: center centres across the main axis (vertically, in a row).

.site-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.main-nav ul {
  display: flex;
  gap: 1.5rem;
}
2

The wobbly links

The cards are the same height, but the “Find the stall” links sit at random heights.

The row of cards is already flex (read-only). First: why are the cards the same height? Then pin every link (.card-link) to the bottom of its card (.vendor-card). Keep the tags their natural width.

Why it works

Cards are the same height because flex items stretch across the cross axis by default (align-items: stretch). Inside each card, make a column; the link's margin-top: auto takes all the free space above it and pushes it down. align-items: flex-start stops the tag and link from stretching to full width.

.vendor-card {
  display: flex;
  flex-direction: column;
  align-items: flex-start;
}
.card-link {
  margin-top: auto;
}
3

Centre the hero

The title sits at the top of the big hero instead of in its middle.

The hero is already min-height: 100vh (read-only). With flex, centre its content vertically. The button must keep its own width. Careful: which axis is vertical in a column?

Why it works

flex-direction: column turns the main axis downwards. justify-content always works along the main axis, so now it centres vertically. align-items works across, now horizontally: flex-start keeps everything left-aligned and stops the button from stretching.

.hero {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: flex-start;
}
4 · bonus

The footer

Put the two lines at the two ends of the footer. When the window is narrow they should wrap onto two lines instead of squashing. Drag the width slider down to 400px to test.

Why it works

Flex items shrink before they wrap. flex-wrap: wrap lets them take a new line instead; gap keeps them apart on either line.

.site-footer {
  display: flex;
  justify-content: space-between;
  flex-wrap: wrap;
  gap: 1rem;
}
5 · bonus

The subscribe row

Input and button on one line, 0.5rem apart. The input takes all the remaining space; the button stays as wide as its text.

Why it works

flex: 1 is short for flex-grow: 1; flex-shrink: 1; flex-basis: 0: start from zero and take all the free space. The button keeps its default (flex: 0 1 auto): as wide as its content.

.subscribe {
  display: flex;
  gap: 0.5rem;
}
.subscribe input {
  flex: 1;
}
6

The name that won't truncate

On a phone the Menu button falls off the card. The long name should end with “…” instead.

The row (.row) is flex. The title (.info h3) already has the ellipsis recipe. The button must stay inside the row at every width, and the title must end in “…”. Drag the width. Why doesn't the recipe work?

Why it works

.info is the flex item, and flex items get min-width: auto: never narrower than their min-content. A nowrap title makes that the whole sentence, so the item won't shrink and the h3 never gets narrower than its text — nothing to truncate. min-width: 0 on the item removes the floor. (overflow: hidden on .info would too: scroll containers have no automatic minimum.)

.info {
  flex: 1;
  min-width: 0;
}
.info h3 {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
