Act 4 · Grid

Draw the floor plan

Grid is the parent drawing lines and the children moving in. The purple dashed lines are the grid lines, with their numbers. Cases 1–4 in class; 5 and 6 if you finish early.

1

The magic line

Six vendors in one long column. The stalls should stand in rows.

Last time you pasted a line you didn't understand. Now write it yourself: as many columns as fit, each at least 16rem, sharing the leftover space, with a 1rem gap. Then drag the window width and watch the columns come and go.

Why it works

Read it inside out. minmax(16rem, 1fr): a column is never narrower than 16rem, and shares the leftover space as 1fr. repeat(auto-fill, …): make as many of those columns as fit in the row. Wide window → more columns; phone → one. No media query needed.

.vendor-list {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
  gap: 1rem;
}
2

The star stall

Dumpling Dynasty is the featured stall: its card should be twice as wide.

Why it works

grid-column: span 2 means: whatever column I start in, cover two. The other cards flow around it into the next free cells.

.featured {
  grid-column: span 2;
}
3

Draw the map

The map should look like the market: here is the floor plan.

┌──────────────────┬───────┐ │ stage │ │ ├───────┬──────────┤ pier │ │ │ table │ │ │ food ├──────────┼───────┤ │ │ crafts │drinks │ ├───────┴──────────┴───────┤ │ gate │ └──────────────────────────┘

The grid's columns and rows are set (read-only), and every zone already has a grid-area name. Draw the map with words: one string per row, one name per cell. Press ◌ target to check against the chalk.

Why it works

Each string is a row; each word is a cell. Repeating a name makes the area cover several cells. Every row needs the same number of cells, and every area must be a rectangle (an L-shape makes the whole declaration invalid). A . is an empty cell.

.market-map {
  grid-template-areas:
    "stage  stage  pier"
    "food   table  pier"
    "food   crafts drinks"
    "gate   gate   gate";
}
4

Line up the insides

The titles have different lengths, so the texts start at different heights. It looks messy.

Make every card's four children (tag, title, text, link) share row lines across all three cards, like the chalk outline. margin-top: auto can't do this: each card only knows itself. The outer grid can. (A subgrid inherits the list's gaps unless you set your own. The target outline uses the inherited ones; any gap passes.)

Why it works

Each card spans 4 rows of the list's grid and, with grid-template-rows: subgrid, lays its own children on those rows instead of making its own. The row with the longest title is as tall as that title, in every card. A subgrid inherits the parent's gaps unless it sets its own.

.vendor-card {
  display: grid;
  grid-row: span 4;
  grid-template-rows: subgrid;
}
5 · bonus

The form, in two columns

Labels in a column on the left, as wide as the longest label. Fields fill the rest. 0.8rem between rows, 1.5rem between columns, labels vertically centred on their fields. The button sits under the fields, as wide as its text.

Why it works

max-content sizes the first column to its widest content, so all the fields line up. The form's children fill the cells in order: label, field, label, field… The button would land in column 1, so it's moved to column 2; justify-self: start stops it from stretching across the cell.

.ticket-form {
  display: grid;
  grid-template-columns: max-content 1fr;
  gap: 0.8rem 1.5rem;
  align-items: center;
}
.ticket-form button {
  grid-column: 2;
  justify-self: start;
}
6 · bonus

Caption on the photo, no position

Lay the caption over the bottom of the photo, full width, without position. The hero must still grow if the caption gets longer.

Why it works

Items placed in the same cell overlap; later in the HTML paints on top (grid items also accept z-index without position). align-self: end drops the caption to the bottom of the cell. Unlike an absolute caption, it still contributes to the row's height.

.hero { display: grid; }
.photo, .caption { grid-area: 1 / 1; }
.caption { align-self: end; }
