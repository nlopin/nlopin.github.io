Flexbox

Line up the stalls

Every button is one declaration. The red arrow is the main axis (justify-content works along it), the blue one the cross axis (align-items). Flip the direction and watch both arrows turn. Click a stall to grow, shrink or push just that one.

Try this

  1. Set justify-content: center, then switch to column. Where did the centring go?
  2. Set align-items: flex-start. Why did the stalls stop being the same height?
  3. Give stall 1 flex-grow: 1. Then stall 2 too. Then stall 2 flex-grow: 2. Is stall 2 now twice as wide? (Read the blue numbers.)
  4. Shrink the container to 30%. Which stalls get squashed? Now give one flex-shrink: 0.
  5. Select the last stall and turn on push it. That's how a "Log in" button ends up on the right of a nav bar.
