One badge, five values of position. The yellow dashed box is the containing block: the box that top and right are measured from. The blue dashed box is the seat the badge keeps in the flow. Scroll the little page for fixed and sticky.

  4. fixed, then scroll. Then sticky + top: 0, then scroll. What's the difference?
