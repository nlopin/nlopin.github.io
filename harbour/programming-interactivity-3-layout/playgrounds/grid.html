Grid lab

Seven numbered boxes in a grid container. Edit anything; the purple lines are the grid lines with their numbers, like DevTools draws them. Drag the window width to see how the tracks respond.

1 · Tracks and fr

Try 200px 1fr 2fr, then repeat(4, 1fr), then repeat(auto-fill, minmax(10rem, 1fr)).

2 · Place by line numbers

Box 1 goes from column line 1 to 3 and row line 1 to 3. Try span, try -1.

3 · Draw with words

Rename the areas, move them around. An L-shaped area breaks the whole declaration: try it.
