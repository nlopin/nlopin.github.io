Layout on one page

Everything from Lecture 3, condensed. Print it, stick it next to your screen.

0 Who decides the width?

flowthe parent (fills it) · height from content
absolutecontent · or left + right
flex itemcontent, then grow / shrink · stretches across
grid itemits track, both ways

Layout surprises you? First ask: which algorithm is in charge? The parent's display and the box's own position decide.

1 Flow

*, *::before, *::after { box-sizing: border-box; }
main { max-width: 72rem; margin-inline: auto; }
.hero { min-height: 100vh; }
  • Blocks stack down, inline boxes flow along the line.
  • Width flows down (from the parent), height grows up (from the children). So height: 50% of an auto-height parent is ignored.
  • auto margins eat leftover space → centring.
  • Vertical margins between blocks collapse: the bigger wins.
  • inline-block: sits in the line, sized like a block.

2 Position

staticdefault, offsets ignored
relativenudge from its seat; seat kept. Anchor for children
absoluteout of flow; from nearest positioned ancestor, else the first screen of the page
fixedout of flow; from the window
stickyflow, then sticks at top while its parent is visible
.card  { position: relative; }
.badge { position: absolute; top: 0; right: 0; }
.cover { position: absolute; inset: 0; }

Who's in front: ① positioned elements paint above normal ones ② then later in the HTML wins ③ z-index overrides (positioned or flex/grid items only; bigger = in front).

3 Flexbox · the container

.nav {
  display: flex;
  flex-direction: row;       /* main axis */
  justify-content: space-between; /* along */
  align-items: center;       /* across */
  flex-wrap: wrap;
  gap: 1rem;
}

justify = along the main axis, align = across. In a column they swap: justify-content: center centres vertically.

Only direct children become flex items.

4 Flexbox · the items

flex: 1take an equal share (a very long word still won't shrink: add min-width: 0)
flex-grow: 1take leftover space
flex-shrink: 0never squash me
flex-basisstarting size (default: content)
margin-left: autopush me (and what follows) to the end
margin-top: autopush me to the bottom of a column
align-selfmy own cross-axis alignment

5 Grid · tracks

.list {
  display: grid;
  grid-template-columns: 200px 1fr 2fr;
  grid-template-rows: auto 10rem;
  gap: 1rem 2rem; /* rows columns */
}
/* the magic line */
grid-template-columns:
  repeat(auto-fill, minmax(16rem, 1fr));

fr = a share of the leftover space. max-content = as wide as the widest content.

6 Grid · placing

.featured { grid-column: span 2; }
.banner   { grid-column: 1 / -1; }
.stage    { grid-column: 2 / 4; grid-row: 1 / 3; }

Numbers are lines: 4 columns have 5 lines. -1 = the last line.

.map {
  grid-template-areas:
    "stage stage pier"
    "food  table pier";
}
.stage { grid-area: stage; }

Same number of cells per row, rectangles only, . = empty. One mistake → whole declaration ignored.

place-items: center centres every item in its cell.

7 Flex or grid?

  • A line of things, sized by their content → flex (nav, buttons, card insides).
  • Rows and columns that must line up → grid (cards, maps, forms, page skeleton).
  • They nest: a grid of cards, each card a flex column.
@media (max-width: 40rem) {
  .market-map {
    grid-template-columns: 1fr 1fr;
    grid-template-areas:
      "stage  stage"
      "food   table"
      "food   crafts"
      "drinks pier"
      "gate   gate";
  }
}

Redraw every area and reset the columns: a zone whose area is missing lands in a stray corner cell.

DevTools: click the flex / grid badge next to an element in the Elements panel to draw its layout.
