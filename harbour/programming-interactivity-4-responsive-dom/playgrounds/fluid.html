Fluid typography

The fluid type calculator

Pick the smallest size and the window where it applies, then the largest size and its window. Between the two, the size follows a straight line: that line is the middle value of clamp(). Drag the window width to see it slide; copy the result into your CSS.

Why the rem part matters

Switch the preferred value to vw only and read the zoom test. Browser zoom makes CSS pixels bigger, so the window gets narrower in CSS pixels: a size made only of vw shrinks by exactly as much as zoom enlarges it. The text never grows. WCAG 1.4.4 asks that text can be resized to 200%. Any fixed part in the middle value keeps it growing with zoom; a rem part also follows the reader's font-size setting.

Try this

  1. Make a headline go from 2.5rem at 360px to 6rem at 1280px.
  2. Make the body text go from 1rem to 1.125rem. Notice how tiny the vw part is: body text should barely move.
  3. Make the minimum larger than the maximum. What does clamp() do? (The minimum wins.)
  4. Find the settings where the zoom test fails even with a rem part. (Hint: a very steep line, a small rem part.)
