The DOM

The page is a tree

Left: a page. Right, top: the tree the browser built from its HTML, live. Right, bottom: a console, like the one in DevTools. Type JavaScript, press Enter, watch the tree and the page change together. Lines that just changed flash red. Hover a line to find its element; click a line to call it $0.

Try this

  1. Click the presets in order, top to bottom. Predict each result before you click.
  2. document.querySelectorAll('.vendor-card')[1]: which card? Why not the first?
  3. Change the date in the eyebrow to Saturday. Then undo it without ↺ reset.
  4. Click a card's line in the tree, then type $0.classList.toggle('featured'). Press ↑ Enter to run it again.
  5. Try document.querySelector('.nope').textContent = 'hi'. Read the error and the hint: you'll see it a lot today.
  6. The same console exists on every website: open DevTools (F12 or ⌥ ⌘ I) on any page and change its headline.
