Responsive + DOM on one page

Everything from Lecture 4, condensed. Print it, stick it next to your screen.

0 Who are you asking?

@mediathe window, the device, the person's settings
clamp() min()nobody: maths that slides

Fewest questions wins: fluid first, a media query when the whole page must change shape. More askers in box 6.

1 The phone

<meta name="viewport"
  content="width=device-width, initial-scale=1">

Without it phones lay the page out at 980px and shrink it. Test: DevTools device toolbar (⌘⇧M), and your real phone via npx live-server's Network URL.

2 Media queries, mobile first

.list { /* phone: one column */ }
@media (width >= 40rem) { /* extras */ }
@media (min-width: 40rem) { /* same, older */ }
  • Breakpoints where your content breaks, in rem. Two or three.
  • A query adds no specificity: put it after the rule it changes.
  • No var() inside a query condition.

4 Variables & calc

@media (width >= 50rem) { :root { --gap: 2.5rem; } }
.card { padding: var(--gap); }

--hue: 30;  color: hsl(var(--hue) 80% 65%);
min-height: calc(100svh - 4rem);
gap: calc(var(--n) * 1rem);

5 Fluid

width: min(100% - 2rem, 40rem);
--gutter: clamp(1rem, 0.2rem + 3.5vw, 3rem);
h1 { font-size: clamp(2.5rem, 1.13rem + 6.09vw, 6rem); }
grid-template-columns:
  repeat(auto-fill, minmax(min(16rem, 100%), 1fr));
  • clamp(MIN, PREFERRED, MAX). The preferred value always gets a rem part (zoom!). Largest ≤ 2.5 × smallest.

7 Find · listen · change

const btn = document.querySelector(".menu-toggle");
btn.addEventListener("click", (event) => {
  btn.setAttribute("aria-expanded", "true");
});

Script tag: <script src="js/market.js" defer>. Without defer in the head, elements don't exist yet → null. Or wrap the code in document.addEventListener("DOMContentLoaded", init).

8 Find

getElementById("id")one element or null, no #
getElementsByTagName("h3")live HTMLCollection

Cannot read properties of null = your selector matched nothing.
