1

The phone menu

On a phone the menu is folded away, and the Menu button does nothing.

The CSS already hides the nav while the button says aria-expanded="false". Make a click flip it to "true", and back. Attributes are strings: "true", not true.

Why it works

The button's aria-expanded is the state, and it's the same attribute a screen reader announces ("Menu, collapsed"). The CSS rule .menu-toggle[aria-expanded="false"] + .main-nav { display: none } draws that state. JavaScript never touches display.

const button = document.querySelector(".menu-toggle");

button.addEventListener("click", () => {
  const isOpen = button.getAttribute("aria-expanded") === "true";
  button.setAttribute("aria-expanded", String(!isOpen));
});
2

Save a stall

Every card has a ♡ Save button. None of them does anything.

A click on a ♡ button toggles that button: aria-pressed goes "false" ↔ "true", and its text becomes ♥ Saved / ♡ Save. You need all the buttons: querySelectorAll gives a list, and a list has no addEventListener. Loop over it.

Why it works

Inside the loop, button is a different element each time round, and each listener remembers its own. event.currentTarget would work too: it's the element the listener is attached to.

const buttons = document.querySelectorAll(".fav");

for (const button of buttons) {
  button.addEventListener("click", () => {
    const saved = button.getAttribute("aria-pressed") === "true";
    button.setAttribute("aria-pressed", String(!saved));
    button.textContent = saved ? "♡ Save" : "♥ Saved";
  });
}
3

The filter, with one listener

Five filter buttons above the vendors. Clicking Food should show only food stalls.

Use one listener, on .filters: clicks on the buttons bubble up to it. In the handler, event.target.closest("button") tells you which button (or null for a click in the gap). Then: the clicked button gets aria-pressed="true", the others "false"; every card whose data-tag doesn't match gets hidden = true. "all" shows everything.

Why it works

A click on a button bubbles: the button, then .filters, then the body, the document. A listener on the parent hears every child. closest("button") walks up from wherever the click landed (maybe a text node inside the button) to the button itself. The [hidden] line in the CSS tab is there because the hidden attribute is just a browser default (display: none), and any author rule that sets display beats it.

const filters = document.querySelector(".filters");
const cards = document.querySelectorAll(".vendor-card");

filters.addEventListener("click", (event) => {
  const button = event.target.closest("button");
  if (!button) return; // a click in the gap

  for (const b of filters.querySelectorAll("button")) {
    b.setAttribute("aria-pressed", String(b === button));
  }
  const tag = button.dataset.filter;
  for (const card of cards) {
    card.hidden = tag !== "all" && card.dataset.tag !== tag;
  }
});
4 · bonus

Escape closes the menu

Case 1 again, plus: pressing Escape anywhere closes the menu. Keys don't happen "on" a button: listen on document for keydown, and check event.key.

Solution
document.addEventListener("keydown", (event) => {
  if (event.key === "Escape") {
    button.setAttribute("aria-expanded", "false");
  }
});

Count what's showing

Your filter from case 3, plus a line under the buttons: 2 of 6 stalls. Write it into .count with a template literal. For "All", leave it empty.

Solution
const count = document.querySelector(".count");
// …inside the click handler, after hiding the cards:
const shown = [...cards].filter((card) => !card.hidden).length;
count.textContent = tag === "all" ? "" : `${shown} of ${cards.length} stalls`;
6 · bonus

JavaScript sets, CSS draws

The bridge between the two halves of today. Each filter button carries a colour in data-color. When a filter is clicked, set the CSS variable --accent on the page root to that colour: document.documentElement.style.setProperty("--accent", …). The stylesheet already paints the cards' borders and the heading with var(--accent). One line in your handler; no colours in your script.

Solution
filters.addEventListener("click", (event) => {
  const button = event.target.closest("button");
  if (!button) return;
  document.documentElement.style.setProperty("--accent", button.dataset.color);
});

JavaScript can also ask CSS's questions: matchMedia("(width >= 40rem)").matches is true exactly when that media query matches.
