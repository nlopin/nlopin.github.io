Lecture 9

Draw, measure, borrow

Three topics. Drawing: HTML boxes, SVG and canvas, vectors and bitmaps. Performance: the Performance panel, then patterns that do less work, like virtualisation and Web Workers. Dependencies: libraries from a CDN without a build step, import maps, versions, and where npm and bundlers take over.
