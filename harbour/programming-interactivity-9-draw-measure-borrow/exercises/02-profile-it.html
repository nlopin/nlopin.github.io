Exercise 2 · Profile it

Three slow pages. Find where the time goes on each one. Don't fix anything yet: fixing is Exercise 3. Pairs, 15 minutes.

Setup

  1. Chrome, in an Incognito or Guest window, so extensions stay out of the recording. Open each page in its own tab.
  2. DevTools (⌥⌘I or F12) → Performance.
  3. Capture settings (the gear) → CPU: 4× slowdown. Every number on this sheet is at 4×.
  4. Record (●), do the action once, Stop. Keep recordings short: a few seconds, one action.
  5. In the recording: find the long task on the Main track, click it, and read the Summary. Then the Bottom-Up tab.
