Jam · task 6

Two-window pong · <window-pong>

Open the page twice, side by side. The ball leaves one window and enters the other. Each window holds one paddle. ★★★

“A game for two people on one laptop, each with their own window, and no server.”

APIs: BroadcastChannel · requestAnimationFrame

Start

⤓ Download the starter

Rather debug than build? The fix-it version hands you a finished <window-pong> with three bugs in it.

Rename the folder to window-pong/, my-tag.js to window-pong.js, and the tag in index.html to <window-pong>. Serve the folder (npx live-server): camera, microphone and the clipboard need localhost or HTTPS. You present from its index.html.

Its gates

  • no secure context, no prompt: same origin is the only rule
  • user activation only if the tag opens the second window itself: window.open outside a click is blocked as a pop-up

Done means · the toy

  • Two windows of the same page find each other and agree who is left and who is right.
  • The ball crosses from one window to the other and comes back.
  • Each window's paddle follows its own keys or pointer.

Then, if there's time

  • Both windows show the same score.
  • Close one window: the other notices and says so.

Done means · the tag contract

  • One file, one element: window-pong.js defines <window-pong> and nothing else. Drop the file into any page and the tag works.
  • Attributes configure, properties carry data, events report: events bubble (bubbles: true), and the page never reaches into your shadow root.
  • Passes its gates in order: nothing starts before a user gesture; if it needs a permission, it reads the state first and asks only after the user asks for the feature.
  • Handles no: a refusal, a missing API or a missing device shows visible content that says what to do; a permission revoked while running is noticed.
  • Releases everything in disconnectedCallback: tracks, AudioContext, animation frames, timers, listeners on window.

Check it (minutes 35–42)

  • Open a third window.
  • Put one window in the background for ten seconds.
  • Reload one window mid-rally.
  • Console: document.querySelector("window-pong").remove(). Is anything still running, playing or recording?

Stretch

  • Use window.screenX so the ball crosses where the windows actually are.
  • A second channel name, a second match.

Traps

Open when something behaves strangely
  • Both windows think they're left.
  • The ball teleports or doubles.
  • The game freezes when one window loses focus.
