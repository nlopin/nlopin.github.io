Jam · task 4

Talk to the page · <voice-command>

Say “dark mode”, the page goes dark. Say “read the headline”, it reads it to you. Build a tag that listens for commands and answers out loud. ★★☆

“My hands are covered in flour and the recipe is on the tablet. Next step, please.”

APIs: SpeechRecognition · SpeechSynthesis

Its gates

  • secure context
  • permission: the microphone prompt
  • user activation for speaking: speechSynthesis.speak() stays silent before the first click
  • Chrome and Safari only; Chrome sends the audio to a server, so it needs the network

Done means · the toy

  • A button starts listening; the element shows what it heard, live.
  • At least five commands change the page around it. The element itself doesn't know what they do: the page listens for command.
  • It answers out loud, and doesn't hear its own voice as a new command.

Then, if there's time

  • Firefox: the element says it can't listen here, and offers a text box instead.
  • Blocked microphone: it says how to allow it.

Done means · the tag contract

  • One file, one element: voice-command.js defines <voice-command> and nothing else. Drop the file into any page and the tag works.
  • Attributes configure, properties carry data, events report: events bubble (bubbles: true), and the page never reaches into your shadow root.
  • Passes its gates in order: nothing starts before a user gesture; if it needs a permission, it reads the state first and asks only after the user asks for the feature.
  • Handles no: a refusal, a missing API or a missing device shows visible content that says what to do; a permission revoked while running is noticed.
  • Releases everything in disconnectedCallback: tracks, AudioContext, animation frames, timers, listeners on window.

Check it (minutes 35–42)

  • Say a command in the middle of a sentence.
  • Turn off Wi-Fi in Chrome.
  • Remove the element while it listens.
  • Block the permission and reload. Then reset it in the site controls next to the address bar.
  • While it runs, revoke the permission in the site controls.

Stretch

  • A wake word.
  • Commands with a parameter: “font size 24”.
  • Interim results, greyed out, replaced by the final one.

Stuck? One hint at a time

Hint 1

Which name does the constructor have in Chrome and Safari today?

Hint 2

Does recognition stop on its own? Which event tells you?

Hint 3

How does the element know when its own speech has finished?

Traps

Open when something behaves strangely
  • It stops listening after a few seconds of silence.
  • It hears its own answer and runs the command again.
  • network error in the console in a classroom.
