Tags that sense something else

The browser has more senses than a camera and a microphone. One group, one tag, one sense. Every tag follows the same contract as the green room's. At the end, each group demos its tag from its own laptop, shared in Zoom.

Every task has a fix-it version: the finished tag with three bugs in it, and the users' reports of what goes wrong. Same API, same 45 minutes.

The contract, for every tag

  • One file, one element: your-tag.js defines <your-tag> and nothing else. Drop the file into any page and the tag works.
  • Attributes configure, properties carry data, events report: events bubble (bubbles: true), and the page never reaches into your shadow root.
  • Passes its gates in order: nothing starts before a user gesture; if it needs a permission, it reads the state first and asks only after the user asks for the feature.
  • Handles no: a refusal, a missing API or a missing device shows visible content that says what to do; a permission revoked while running is noticed.
  • Releases everything in disconnectedCallback: tracks, AudioContext, animation frames, timers, listeners on window.

Testing without the hardware

  • Reset a blocked permission: the site controls next to the address bar → reset permissions, then reload.
  • DevTools → ⋮ → More tools → Sensors: fake device orientation and location.
  • Chrome started with --use-fake-device-for-media-stream gives a test pattern and a beep instead of your camera and microphone; add --use-fake-ui-for-media-stream to skip the prompt.
