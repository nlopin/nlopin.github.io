Jam · task 3

Photo booth · <photo-booth>

A countdown, a flash, four shots in a strip, one download. The booth from the shopping mall, as a tag. ★★☆

“Wedding guests queue for the photo booth all night. I want one on a tablet by the door.”

APIs: getUserMedia · drawImage · canvas.toBlob

Start

⤓ Download the starter

Rather debug than build? The fix-it version hands you a finished <photo-booth> with three bugs in it.

Rename the folder to photo-booth/, my-tag.js to photo-booth.js, and the tag in index.html to <photo-booth>. Serve the folder (npx live-server): camera, microphone and the clipboard need localhost or HTTPS. You present from its index.html.

Its gates

  • secure context
  • permission: the camera prompt

Done means · the toy

  • The camera starts only after the user asks for it, with a sentence saying why first.
  • shoot(): countdown, a flash, a shot, repeated shots times, then the strip appears.
  • The strip downloads as one PNG.

Then, if there's time

  • Blocked camera: the element explains how to allow it, and stays useful (e.g. a strip from uploaded photos).
  • A row of the last three strips, kept in memory only.

Done means · the tag contract

  • One file, one element: photo-booth.js defines <photo-booth> and nothing else. Drop the file into any page and the tag works.
  • Attributes configure, properties carry data, events report: events bubble (bubbles: true), and the page never reaches into your shadow root.
  • Passes its gates in order: nothing starts before a user gesture; if it needs a permission, it reads the state first and asks only after the user asks for the feature.
  • Handles no: a refusal, a missing API or a missing device shows visible content that says what to do; a permission revoked while running is noticed.
  • Releases everything in disconnectedCallback: tracks, AudioContext, animation frames, timers, listeners on window.

Check it (minutes 35–42)

  • Call shoot() twice quickly.
  • document.querySelector('photo-booth').remove() mid-countdown.
  • Block the permission and reload. Then reset it in the site controls next to the address bar.
  • While it runs, revoke the permission in the site controls.

Stretch

  • One filter, applied to the pixels, not with CSS.
  • A mirrored preview but an unmirrored photo (or the opposite: which is right?).
  • navigator.share on phones.

Traps

Open when something behaves strangely
  • The first photo is black.
  • The strip is the wrong size or squashed.
  • Two strips interleave when shoot() is called during a countdown.
  • The camera light stays on after the element is gone.

On stage · 3 minutes
