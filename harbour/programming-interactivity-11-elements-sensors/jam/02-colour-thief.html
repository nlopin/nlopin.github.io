Jam · task 2

Colour thief · <colour-thief>

See a colour anywhere on screen, steal it. Build a palette you fill by pointing at things, copy from, and keep. ★★☆

“Half my day is copying colours from screenshots into CSS. I want a palette that lives on my page and remembers.”

APIs: EyeDropper API · Clipboard API · localStorage

Start

⤓ Download the starter

Rather debug than build? The fix-it version hands you a finished <colour-thief> with three bugs in it.

Rename the folder to colour-thief/, my-tag.js to colour-thief.js, and the tag in index.html to <colour-thief>. Serve the folder (npx live-server): camera, microphone and the clipboard need localhost or HTTPS. You present from its index.html.

The tag's public API

Keep these names. Add more if you need them.

attributemaxhow many colours the palette keeps (oldest drop off)

Its gates

  • secure context: localhost or HTTPS
  • user activation for both the picker and the clipboard write
  • no prompt: the picker itself is the consent

Done means · the toy

  • Pick opens the system's eyedropper; the colour lands in the palette.
  • Click a swatch: its hex is on the clipboard, and the element says so.
  • Export copies the palette as CSS custom properties.

Then, if there's time

  • The palette survives a reload.
  • Where EyeDropper doesn't exist (Firefox, Safari), the element still adds colours another way, and says why.

Done means · the tag contract

  • One file, one element: colour-thief.js defines <colour-thief> and nothing else. Drop the file into any page and the tag works.
  • Attributes configure, properties carry data, events report: events bubble (bubbles: true), and the page never reaches into your shadow root.
  • Passes its gates in order: nothing starts before a user gesture; if it needs a permission, it reads the state first and asks only after the user asks for the feature.
  • Handles no: a refusal, a missing API or a missing device shows visible content that says what to do; a permission revoked while running is noticed.
  • Releases everything in disconnectedCallback: tracks, AudioContext, animation frames, timers, listeners on window.

Check it (minutes 35–42)

  • Press Esc while picking.
  • Firefox or Safari: what does the user see?
  • Two <colour-thief> on one page with different storage-keys.
  • Console: document.querySelector("colour-thief").remove(). Is anything still running, playing or recording?

Stretch

  • Show the contrast ratio of each swatch against white and black.
  • Name the closest CSS named colour.
  • Drag a swatch to reorder.

Traps

Open when something behaves strangely
  • Copying works from a click on a swatch, but not right after picking a colour.
  • AbortError in the console every time someone presses Esc.
  • Two thieves on one page overwrite each other's palette.
