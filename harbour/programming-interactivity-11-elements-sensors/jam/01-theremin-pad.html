Jam · task 1

Theremin · <theremin-pad>

The first electronic instrument you play without touching it: one hand sets the pitch, the other the volume. Build one you play with the pointer. ★☆☆

“I want something for the kids' corner at the science museum: touch the screen, it sings, move and it changes.”

APIs: Web Audio API · Pointer Events · Canvas

Its gates

  • no secure context needed
  • user activation: no sound before the first press
  • no prompt

Done means · the toy

  • Press and move: left to right raises the pitch, bottom to top raises the volume. Release: silence.
  • Works with a mouse, a trackpad and a finger on a phone: one code path.
  • The waveform you hear is drawn live on a canvas inside the element.

Then, if there's time

  • Changing wave in DevTools changes the sound while it plays.
  • Pressing outside and dragging in, or leaving the pad while pressed, never leaves a note stuck on.

Done means · the tag contract

  • One file, one element: theremin-pad.js defines <theremin-pad> and nothing else. Drop the file into any page and the tag works.
  • Attributes configure, properties carry data, events report: events bubble (bubbles: true), and the page never reaches into your shadow root.
  • Passes its gates in order: nothing starts before a user gesture; if it needs a permission, it reads the state first and asks only after the user asks for the feature.
  • Handles no: a refusal, a missing API or a missing device shows visible content that says what to do; a permission revoked while running is noticed.
  • Releases everything in disconnectedCallback: tracks, AudioContext, animation frames, timers, listeners on window.

Check it (minutes 35–42)

  • Mute your laptop. Can someone still tell what the pad is doing?
  • Remove the element in the console while a note plays.
  • Phone: does the page scroll when you drag on the pad?

Stretch

  • Snap to the notes of a scale, with an attribute to choose the scale.
  • Two fingers, two voices.
  • A record method and a loop event.

Traps

Open when something behaves strangely
  • The first click makes no sound; the second one does.
  • Clicks and pops every time the pitch changes.
  • The note keeps playing after you let go outside the pad.
  • Everything works on desktop; on the phone the page scrolls instead.
