Clap switch · <clap-switch>

Clap twice, the light goes on. The 1980s gadget, in a tag that listens to the room. ★★☆

“I want to start my slides by clapping. Twice. Not when someone coughs.”

APIs: getUserMedia · AnalyserNode

The tag's public API

Keep these names. Add more if you need them.

kindnamemeaning
attributeclapsclaps needed to switch, default 2
attributethresholdhow loud a clap is, 0–1
methodstart()starts listening, the same as the element's own start button; call it from a click
eventclapeach clap: detail: { count, level }, count = claps so far in this sequence
eventtogglethe switch flips, after claps claps: detail: { on }

Its gates

  • secure context
  • permission: the microphone prompt
  • user activation for the AudioContext

Done means · the toy

  • A live level meter, so the user sees what it hears.
  • Two claps within a second flip the switch; one clap, talking or a cough don't.
  • The threshold is adjustable from the page, and the meter shows where it is.

Then, if there's time

  • The page around it reacts to toggle (the element only reports).
  • The switch's state is reflected as an on attribute, so the page can style it.

Done means · the tag contract

  • One file, one element: clap-switch.js defines <clap-switch> and nothing else. Drop the file into any page and the tag works.
  • Attributes configure, properties carry data, events report: events bubble (bubbles: true), and the page never reaches into your shadow root.
  • Passes its gates in order: nothing starts before a user gesture; if it needs a permission, it reads the state first and asks only after the user asks for the feature.
  • Handles no: a refusal, a missing API or a missing device shows visible content that says what to do; a permission revoked while running is noticed.
  • Releases everything in disconnectedCallback: tracks, AudioContext, animation frames, timers, listeners on window.

Check it (minutes 35–42)

  • Clap three times.
  • Play music from your phone next to the laptop.
  • Block the microphone, then allow it again without reloading.
  • Block the permission and reload. Then reset it in the site controls next to the address bar.
  • While it runs, revoke the permission in the site controls.
  • Console: document.querySelector("clap-switch").remove(). Is anything still running, playing or recording?

Stretch

  • Whistle detection from the frequency data.
  • Calibrate: measure the room's noise for two seconds first.

Stuck? One hint at a time

Hint 1

What separates a clap from speech: how loud, or how fast it gets loud?

Hint 2

After a clap is detected, how long should the element ignore the input?

Traps

Open when something behaves strangely
  • One clap counts as three.
  • Works at home, triggers constantly in the classroom.
  • The meter freezes when the tab is in the background, and the count is wrong after.
