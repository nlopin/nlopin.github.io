Lecture 11

Tags that listen

HTML tags you write yourself: custom elements, their lifecycle, attributes and properties, shadow DOM, slots, and form-associated elements with keyboard support and roles. Then the browser's sensors: secure contexts, permissions, user activation, Permissions Policy, the camera and the microphone, and releasing them when the element leaves the page. Then a jam: one sensing tag per group, demoed over Zoom.
