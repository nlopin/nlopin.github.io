A · another origin, no allow

The default allowlist for camera and microphone is 'self': a frame from another origin can't use them, and no prompt appears.


      
    


    

      
B · another origin, allow="camera; microphone"

      
The embedding page delegates both features. The frame can use them; in Chrome the prompt names this page's origin (the top-level page), not the frame's, and the answer is stored for this page.

      

      
    


    

      
C · same origin, allow="camera 'none'; microphone 'none'"

      
The embedding page can also take a feature away, even from its own origin.
