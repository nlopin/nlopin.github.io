The Web Pub Quiz

Seven rounds of real-or-fake and spot-the-difference about the web: logos, forgotten HTML tags, CSS colours, JavaScript surprises, HTTP status codes, npm packages and websites drawn as boxes.

▶ Open the slides🖨 Answer sheet

Before the night

  • Print one answer sheet per team (two A4 pages), plus pens.
  • Have a laptop with a browser for question 7.5: you'll count the elements on en.wikipedia.org/wiki/World_Wide_Web live. At prep time (October 2026) the count was 6,254.
  • Something to keep the running score on: a whiteboard works.

Running it

  • Each round runs twice: first all the questions, then an “Answers” slide and the same questions again. On the answer pass, press → once to reveal each answer.
  • Press p for the presenter window: it shows each slide's answer and the story behind it.
  • One point per answer. Closest-guess questions (6.3, 7.5) give 2 points to the closest team only.

Making more grey-box pictures

Open any page, paste this into the console, and take a screenshot:

document.head.insertAdjacentHTML("beforeend", `<style>
  *, *::placeholder, *::before, *::after {
    color: transparent !important; -webkit-text-fill-color: transparent !important;
    background: #ddd !important; border-color: #999 !important;
    text-shadow: none !important; box-shadow: none !important; }
  * { outline: 1px solid #999; }
  img, svg, video, canvas, picture, iframe { opacity: 0 !important; }
</style>`);

Parts of a page inside shadow DOM (MDN's live examples, for one) need the same style added to each shadow root.
