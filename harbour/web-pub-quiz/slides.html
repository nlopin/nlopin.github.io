Pub Quiz

7 rounds · about an hour · one winner

Hand out one answer sheet per team (answer-sheet.html, printed) and a pen. Teams of 3–5.

Keys: → next step / slide · p presenter window with these notes · m menu · f fullscreen. Each round shows all its questions first, then an “Answers” slide, then the same questions again: on those, press → once to reveal each answer.

Before we start

House rules

  • Teams of 3 to 5. Give your team a name and write it on the sheet.
  • Phones and laptops stay closed. Your brain is the only runtime.
  • One point per answer. Closest guess questions: 2 points to the closest team.
  • The quizmaster's answer is final, even when it's undefined.

Scoring: real-or-fake tiles are one point each, so rounds 2, 3, 5 and 6 are worth roughly 10 each. Keep a running total on a whiteboard between rounds.

A
B

Answer: A, the lighter one. darkgray (#A9A9A9) comes from X11, where it was a light grey. gray (#808080) comes from the older HTML colour list. When the two lists merged, nobody fixed the names.

Round 3 · Question 12

What colour is this table cell?

<td bgcolor="chucknorris">

Answer: red. The cell on the slide really is bgcolor="chucknorris". The old HTML colour parser never rejects a value: it replaces every character that isn't a hex digit with 0, splits what's left into three parts and keeps the first two digits of each: c00 0000 0000 → #c00000. Accept “red” or “dark red”.

Round 3 · Question 13

#663399

Answer: Eric Meyer's daughter. Rebecca died of brain cancer on her sixth birthday in 2014; purple was her favourite colour. The CSS Working Group added the name the same year. Read the answer gently.

Round 4 · Question 1

What does this evaluate to?

"b" + "a" + +"a" + "a"

Answer: "baNaNa". +"a" is the unary plus: it converts "a" to a number, which is NaN, and then NaN is joined into the string. Half a point for “banana”.

Round 4 · Question 2

What does this return?

[10, 1, 3].sort()

Answer: [1, 10, 3]. The fix is .sort((a, b) => a - b).

Round 4 · Question 3

What does this return?

Math.max()

Answer: -Infinity. And Math.min() is Infinity.

Round 4 · Question 4

What does this return?

typeof NaN

Answer: "number". Bonus chaos: NaN === NaN is false.

Round 4 · Question 5

What does this evaluate to?

[] + {}

Answer: "[object Object]". The same string the market's localStorage bug stored when you forgot JSON.stringify.

Round 4 · Question 6

True or false? One point for all three.

null >= 0   // ?
null > 0    // ?
null == 0   // ?

Answer: true, false, false. So null is greater than or equal to zero, without being greater than zero or equal to zero.

Answer: A. Identifiers may use any Unicode letter (ID_Start / ID_Continue). Emoji are symbols, not letters.

Real HTTP status or fake?

9 questionsEight codes, with their names. R or F.

Round 5 · Questions 1–8

Could a server send this back?

  • 418I'm a teapot
  • 451Unavailable For Legal Reasons
  • 299Probably Fine
  • 420Enhance Your Calm
  • 103Early Hints
  • 404½Partially Found
  • 226IM Used
  • 499Too Many Tabs Open

Fake: 3, 6, 8. Item 4 (420) gets half a point for either answer.

418: from an April Fools' RFC in 1998 about controlling coffee pots over HTTP; servers kept it as a joke, and the standard now reserves the code. 451: for pages blocked by law, added in 2016. 103 Early Hints: the server tells the browser what to preload before the real response is ready. 226 IM Used: from a 2002 RFC on sending only the changes to a page; almost nobody uses it. 420: Twitter's old API sent it when you were rate-limited.

Round 5 · Bonus

Answer: Fahrenheit 451.

npm: 1, 3, 6, 7, 10, 11. Pokémon: 2, 4, 5, 8, 9, 12. Read each name aloud too: half the fun is how they sound.

nodemon restarts a Node server when files change. chokidar watches files (it's Hindi for “watchman”). rimraf is rm -rf for Node. yargs parses command-line arguments. execa runs shell commands. pino is a logger. Sudowoodo is a tree that pretends to be a tree. Porygon is literally a computer program in the Pokémon lore. Klink is a pair of gears.

Round 6 · Question 13

The npm package is-even checks whether a number is even. It depends on one other package. Which one?

Answer: is-odd. And is-odd depends on is-number.

Round 6 · Question 14 · closest guess

In 2016, one developer deleted left-pad from npm, and builds broke all over the internet. How many lines of code was it?

Answer: 11. Two points to the closest team. After a name dispute over another package, its author unpublished all 273 of his packages. npm changed its rules afterwards: you can't unpublish a package that others depend on.

Round 6 · Question 15

mocha is a test runner on npm. What else in this quiz was once called Mocha?

Answer: JavaScript. Brendan Eich wrote it in 10 days in May 1995; it was renamed LiveScript, then JavaScript, while Java was popular.

Round 6 · Question 16

In 2018, a stranger took over the popular package event-stream and hid malicious code in it. What was it trying to steal?

Answer: bitcoin (accept “crypto wallets”). The original author had handed the package to a volunteer who asked to help; the volunteer added a dependency, flatmap-stream, with the payload. A library runs with all of your page's rights.

Round 6 · Question 17

In 2022, the author of colors broke his own package on purpose. Apps that updated printed one word, forever. Which word?

Answer: LIBERTY. The package had over 20 million weekly downloads. Pin your versions.
