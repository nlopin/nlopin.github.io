Exercise 1 · Nearest defibrillator

Someone collapses in the street. The nearest public defibrillator (AED) is somewhere within a few hundred metres. Build the page that says where: a map, the user's position, and the five nearest AEDs from OpenStreetMap.

Start

⤓ Download the starterThe data ↗
  • Extract the zip and serve the folder from a local server. Opening index.html as a file doesn't work: module scripts and fetch need http://, and geolocation needs localhost or HTTPS.
cd 01-nearest-defibrillator
npx live-server --port=8080

It opens http://127.0.0.1:8080 and reloads the page when you save. Without Node: VS Code's Live Server extension, or python3 -m http.server 8080 (no reload).

  • data/defibrillators.json: all 706 AEDs mapped in Barcelona, an OpenStreetMap snapshot from 1 June 2026, in the Overpass API's format.

Done means

  • Leaflet 1.9.4 loads from a CDN (unpkg or jsDelivr) through an import map: its ES module build, at an exact version.
  • Leaflet's CSS loads with an integrity hash. Change one character of the hash: what does the console say?
  • The map shows OpenStreetMap tiles, with the attribution the data's licence requires.
  • Locate me puts the user on the map, with the accuracy visible. Nothing asks for the location before the click.
  • Blocked, unavailable or timed out: the status line says which, and a click on the map sets the position instead.
  • The five nearest AEDs: in the list, nearest first, with the distance in metres and where to find it (defibrillator:location, when the data has it); and as markers on the map.

Check it

  • DevTools → Sensors → Location: London. What does the list say now?
  • Sensors → Location: "Location unavailable". Then block the permission in the site settings and reload.
  • Network → Offline, reload. Which requests fail, and are they code or data?
  • Network panel, filter by the CDN's domain: how many requests, how many kB, for one import?
  • Use the list with the keyboard only. Can you tell where the nearest AED is without seeing the map?

Stretch

  • Vendor Leaflet: the same files in vendor/, with its licence, and the import map pointing there. Offline, the code still loads.
  • watchPosition: the list updates as you walk. Stop watching when the page is hidden.
  • Load Leaflet with import() on the first click, with a loading state.
  • Replace the snapshot with a live query around the user, from the Overpass API: node["emergency"="defibrillator"](around:1000,LAT,LON);out;. Public instances answer 406, 429 and 504 under load: what does your page do then?
