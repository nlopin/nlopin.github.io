Lecture 8

Over the wire

The Harbour Night Market stops reading its vendors from a file and starts talking to a server. HTTP requests and responses, the event loop and promises (.then and async/await), fetch and the Response object, loading and error states, sending data with POST and handling validation errors, CORS, and responses that arrive out of order. Then 45 minutes building a feature against a real server.
