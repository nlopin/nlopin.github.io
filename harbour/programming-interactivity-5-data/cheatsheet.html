Data in, page out on one page

Everything from Lecture 5, condensed. Print it, stick it next to your screen.

0 The idea

// page = render(state)
someElement.addEventListener("click", () => {
  state.something = …;  // 1 · change the state
  update();             // 2 · render() + save()
});

Events never patch the page. They update state; render() re-renders everything from it.

4 Render

const template = document.querySelector("#stall-template");

function card(stall) {
  const li = template.content.firstElementChild.cloneNode(true);
  li.dataset.id = stall.id;
  li.querySelector("h3").textContent = stall.name;
  li.querySelector(".vendor-card").classList.toggle("sold-out", Boolean(stall.soldOut));
  return li;
}

function render() {
  list.replaceChildren(...visibleStalls().map(card));
}

textContent for data, never innerHTML. replaceChildren removes the old ones first: safe to call again. toggle(name, undefined) flips: pass a real boolean.

5 State

const state = { tag: "all", query: "", saved: new Set() };

function visibleStalls() {           // derived
  return stalls.filter((s) => state.tag === "all" || s.tag === state.tag);
}
  • In the state: user input only. Derived state (counts, visible list): computed on render, never stored.
  • Cards are redrawn: listen on the list (delegation), event.target.closest(".save").
  • Controlled inputs: render() sets aria-pressed, checkbox.checked, input.value from the state.
  • Every listener: change state, then update() = render(); save();
  • Set: add, delete, has, size, [...set].

6 Persistence

function save() {
  const data = { tag: state.tag, saved: [...state.saved] };
  localStorage.setItem(KEY, JSON.stringify(data));
}
function load() {
  try {
    const data = JSON.parse(localStorage.getItem(KEY));
    if (!data) return;
    state.tag = data.tag ?? "all";
    state.saved = new Set(data.saved ?? []);
  } catch { /* keep the defaults */ }
}
load(); render();

7 Modules

// index.html: one entry point
<script type="module" src="js/main.js"></script>
  • Own scope per file: no more "already declared".
  • "./data.js": relative, with .js.
  • Needs http:// (npx live-server); deferred automatically.
  • Imports are read-only: change keys, don't reassign.
