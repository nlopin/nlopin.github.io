Arrays

Array lab

Type a chain of array methods and press Enter. Every step gets its own row, so you can see what each method hands to the next one. Every line starts again from the original data. A line that changes the data gets a warning row: that's how you spot sort, reverse and push.

Try this

  1. Click every preset once. Predict the result first: an array, one object, a number, true/false?
  2. The names of the open food stalls, cheapest first. (Three methods, chained.)
  3. The price of Mezcal Moon, in one line. What happens with an id that doesn't exist? Fix it with ?.
  4. Find the preset that changes stalls. Then rewrite it so it doesn't.
  5. stalls.map((s) => { name: s.name }) gives undefineds. Why? (Look at the last preset.)
