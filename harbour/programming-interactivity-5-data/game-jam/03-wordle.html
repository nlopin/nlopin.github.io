Game jam · game 3

Wordle

Guess the five-letter word in six tries. After each guess every letter turns 🟩 (right letter, right place), 🟨 (in the word, somewhere else) or ⬜ (not in the word). ★★☆

“SLATE first. Always SLATE.”

You'll demo: type a word on the keyboard, press Enter: the row colours in, and so do the keys of the on-screen keyboard. A word that isn't in the list is refused. Six misses: the answer is shown.

Must have (tick as you go)

What has to work, not how. The how is your call: you'll explain it on stage.

State

  • The answer and the guesses so far.
  • The letters typed into the current row.

Render

  • Six rows of five tiles drawn from state, submitted rows coloured.
  • An on-screen keyboard. Each key shows the best colour its letter has earned so far.
  • A message line: not in the list, you won, or the answer.

Rules

  • Physical keys type letters, Backspace deletes, Enter submits. The on-screen keys do exactly the same.
  • Enter accepts only a full row that's in the word list.
  • After a win or the sixth guess, typing does nothing.

The one rule: the DOM is output. The current row lives in state, not in the tiles.

Edge cases (verify, minutes 35–42)

  • The four rows in the table above.
  • Backspace on an empty row. Enter with four letters.
  • A key that was 🟨 in one guess and 🟩 in the next: which colour does it keep?
  • Cmd/Ctrl + R reloads the page and doesn't type an R.
  • Click an on-screen key, then press the physical Enter.

Stretch, if you're done early

  • An invalid word shakes the row.
  • A share button: copies the result as a grid of 🟩🟨⬜ to the clipboard, without the letters.
  • A daily word: everyone who opens the page today gets the same one.
  • Everyone's stretch: undo (one letter? one guess?), save, best score (a win streak).

Stuck? One hint at a time

Try for five minutes first.

Hint 1

The colours of a submitted row never change. Do you need to store them?

Hint 2

Look at SPEED against ABIDE. Why is the first E yellow and the second one grey? Say the rule in one sentence before you code it.

Hint 3

Physical keys and on-screen keys do exactly the same thing. In how many places should that logic live?

Traps

Open when something behaves strangely
  • After clicking an on-screen key, the physical Enter does something extra.
  • Some letters arrive in the wrong case.
  • Keyboard shortcuts type letters.
