Act 5 · ES modules

Split into modules

Today's whole market lives in one script, js/market.js, and every name in it is global: the reason the jam's "has already been declared" error existed. Split it into ES modules: same behaviour, five files, one responsibility each.

Two keywords. export in front of what a file offers; import { name } from "./file.js" at the top of a file that needs it. Everything else stays private to its file.

Before you start

  1. Copy project/starter/ out of the repo into your own folder (or unzip starter.zip there). Don't edit inside the repo: the next git pull would conflict with your changes.
  2. Serve it: npx live-server in that folder. Modules don't load from file://.
  3. Open js/market.js. It's today's market in one file, in numbered sections. Every name in it is global: type stalls into the console and it answers.

The target

The same page, the same behaviour, five files. Arrows are imports. main.js is the only file the HTML loads.

index.html <script type="module" src="js/main.js"> └─ main.js events, update(), start sections 5–8 ├─ render.js card(), render() section 4 │ ├─ state.js │ └─ data.js ├─ storage.js save(), load() section 3 │ └─ state.js └─ state.js state, visibleStalls(), section 2 │ toggleSaved() └─ data.js export const stalls section 1

Steps

  1. data.js. Move section 1 into js/data.js and put export in front of const stalls.
  2. state.js. Section 2. It uses stalls, so its first line is an import. Export what other files need. 
    import { stalls } from "./data.js";

export const state = { … };
export function visibleStalls() { … }
  3. storage.js (section 3) and render.js (section 4): same idea. Each file imports only what it uses. Leave update() for main.js.
  4. main.js. Sections 5–8: update(), the listeners, the menu, the form, the start. It imports from the other four.
  5. index.html. Replace the old script tag, then delete market.js. 
    <script type="module" src="js/main.js"></script>

The requested module './state.js' does not provide an export named 'visibleStalls'Forgot the export, or a spelling difference between the two files.
stalls is not definedThis file uses a name it never imported. Every module starts with an empty scope.
Assignment to constant variableAn imported binding is read-only: state = … fails in another file. Change its keys instead: state.tag = ….
