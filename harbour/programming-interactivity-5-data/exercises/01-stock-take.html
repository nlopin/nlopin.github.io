Act 1 · The market is data

Stock-take

Seven small pure functions over the market data. The market (🔒, read only) runs first; your function goes underneath. The checks also call your function with a different market, so hard-coding the answer won't pass.

The three you'll use most. list.map(s => …): transforms each element. list.filter(s => …): the elements matching a predicate. list.find(s => …): the first element matching the predicate, or undefined. None of them mutates list.

1

Every name

The poster printer wants a plain list of names.

Write names(list): it gets an array of stalls and returns an array of their names, in the same order. One line with .map().

Solution

map calls your function once per item and collects what it returns into a new array of the same length. stalls itself doesn't change.

function names(list) {
  return list.map((stall) => stall.name);
}
2

Only the food

The info desk needs the food stalls only.

Write byTag(list, tag): the stalls whose tag matches, as an array of whole stall objects. A tag nobody has gives an empty array.

Solution

filter keeps every item for which your function returns true. The result can be shorter, or empty, never longer. Compare with ===: a single = would assign the tag (and every stall would match).

function byTag(list, tag) {
  return list.filter((stall) => stall.tag === tag);
}
3

Find one stall

The map has stall ids. Which stall is “mezcal”?

Write findStall(list, id): the stall object with that id, or undefined if there is none.

Solution

find stops at the first element for which the predicate returns true and returns that element, not an array. Nothing matches → undefined, so check before you use it: findStall(stalls, id)?.name.

function findStall(list, id) {
  return list.find((stall) => stall.id === id);
}
4

How many are open?

The night is busy. How many stalls are still selling?

Write openCount(list): the number of stalls that are not sold out.

Solution

Two steps: keep the open ones, count them. !stall.soldOut reads "not sold out".

function openCount(list) {
  return list.filter((stall) => !stall.soldOut).length;
}
5

Cheapest first

A student budget. Sort by price, cheapest first, but don't mess up the market's own order.

Write cheapestFirst(list): a new array, sorted by price, lowest first. stalls must keep its original order: sort() changes the array you call it on.

Solution

sort() sorts in place and, without a compare function, compares items as text ("10" comes before "9"). Copy with spread, then sort with (a, b) => a.price - b.price: negative means a first. Newer browsers also have list.toSorted(…), which copies for you.

function cheapestFirst(list) {
  return [...list].sort((a, b) => a.price - b.price);
}

Homework · cases 6–7

6

A label for the poster

Write label(stall): "Dumpling Dynasty · food · from €8". A price of 0 says free; a sold-out stall ends with · sold out: "Mezcal Moon · drinks · from €9 · sold out". Use a template literal; destructuring is a nice touch.

Solution

Destructuring pulls the fields into names; cond ? a : b picks one of two values; backticks put values into a string.

function label({ name, tag, price, soldOut }) {
  const cost = price === 0 ? "free" : `from €${price}`;
  return `${name} · ${tag} · ${cost}` + (soldOut ? " · sold out" : "");
}
7 · bonus

Which kinds of stall?

Write tags(list): every tag once, in the order it first appears: ["food", "music", "crafts", "drinks"]. A Set keeps only one of each; spread turns it back into an array.

Solution

A Set is a collection where every value appears once, in the order it was added. It isn't an array (no map), so spread it: [...set].

function tags(list) {
  return [...new Set(list.map((stall) => stall.tag))];
}
