Act 2 · Rendering

Render the market

The vendor list is empty: the page has a <template> for one card and an array of stalls; your script renders the list from the array. Change the data, re-run, and the DOM follows.

The pattern. card(stall): maps a record to an element. render(list): container.replaceChildren(...list.map(card)). Text goes in with textContent.

1

One card from one stall

The cards are typed into the HTML by hand. Every new stall means copy-paste.

The card's HTML is in a <template> (look at the index.html tab): the browser parses it but doesn't show it. Finish card(stall): clone the template, fill in the tag, the name and the blurb with textContent, put the stall's id on the <li> as data-id, and return it.

Solution

template.content is a little document of its own; cloneNode(true) copies the <li> with everything inside. Fill it with textContent, never innerHTML: the data might come from user input.

const template = document.querySelector("#stall-template");

function card(stall) {
  const li = template.content.firstElementChild.cloneNode(true);
  li.dataset.id = stall.id;
  li.querySelector(".tag").textContent = stall.tag;
  li.querySelector("h3").textContent = stall.name;
  li.querySelector(".blurb").textContent = stall.blurb;
  return li;
}

document.querySelector(".vendor-list").append(card(stalls[0]));
2

Render the whole list

Eight stalls today, twelve tomorrow. The DOM should reflect the array, whatever it contains.

card() is done (🔒). Write render(list): replace whatever is in .vendor-list with one card per stall, and write the count into .count: "8 stalls", "1 stall", "0 stalls". Call render(stalls) at the end. Calling it twice must not double the cards.

Solution

stallsToShow.map(card) maps records to elements; spread passes them to replaceChildren, which throws the old children away first. That's why render is idempotent: it always rebuilds from scratch.

const list = document.querySelector(".vendor-list");
const count = document.querySelector(".count");

function render(stallsToShow) {
  list.replaceChildren(...stallsToShow.map(card));
  const n = stallsToShow.length;
  count.textContent = `${n} ${n === 1 ? "stall" : "stalls"}`;
}

render(stalls);
3

Sold out, and a price

Churros and Mezcal sold out an hour ago, and the page still sells them.

Extend card() from data to looks: a sold-out stall gets the class sold-out on its .vendor-card and shows the .badge (it starts hidden). Every card shows its price in .price: "from €8", or "free" for 0. Some data has no soldOut key at all: that stall is open.

Solution

classList.toggle(name, condition) adds the class when the condition is true and removes it when false: one line for both cases. One trap: toggle("sold-out", undefined) counts as no second argument and flips the class. A stall without a soldOut key has undefined there, so turn it into a real boolean first: Boolean(stall.soldOut).

const template = document.querySelector("#stall-template");

function card(stall) {
  const li = template.content.firstElementChild.cloneNode(true);
  li.dataset.id = stall.id;
  li.querySelector(".tag").textContent = stall.tag;
  li.querySelector("h3").textContent = stall.name;
  li.querySelector(".blurb").textContent = stall.blurb;
  li.querySelector(".price").textContent = stall.price === 0 ? "free" : `from €${stall.price}`;
  const soldOut = Boolean(stall.soldOut); // a missing key is undefined
  li.querySelector(".vendor-card").classList.toggle("sold-out", soldOut);
  li.querySelector(".badge").hidden = !soldOut;
  return li;
}

const list = document.querySelector(".vendor-list");
list.replaceChildren(...stalls.map(card));

Grouped by tag

Render one <section class="group"> per tag, in the order tags first appear, each with an <h3> (the tag) and its own <ul class="vendor-list"> of cards. Put the sections into #groups. card() is done.

Solution

First the list of tags (Exercise 1, case 7), then one section per tag, with a filter inside. Elements built with createElement can hold other elements: append takes as many as you give it.

const groups = document.querySelector("#groups");
const tags = [...new Set(stalls.map((s) => s.tag))];

groups.replaceChildren(...tags.map((tag) => {
  const section = document.createElement("section");
  section.className = "group";
  const title = document.createElement("h3");
  title.textContent = tag;
  const ul = document.createElement("ul");
  ul.className = "vendor-list";
  ul.append(...stalls.filter((s) => s.tag === tag).map(card));
  section.append(title, ul);
  return section;
}));
