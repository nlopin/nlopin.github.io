Lecture 5

Data in, page out

The Harbour Night Market's vendor list stops being typed into the HTML. It becomes an array of objects, and the DOM is rendered from it: array methods, a <template> and a render() function, a single state object, persistence with localStorage, ES modules, and the debugger.
